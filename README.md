# Dota Draft Copilot

Настольный помощник для драфта Dota 2 на Windows. Смотрит на экран выбора героев,
определяет ваш состав и врагов, затем показывает:

- **контрпики** с учётом вашей роли и того, чего не хватает союзному составу,
  с поиском и фильтрами по характеристикам героев;
- **сборку по фазам** (старт, ранняя игра, мид, лейт) и ситуативные предметы против
  угроз врага — крупными иконками, с названием и ценой по наведению;
- **нейтральные предметы** по тирам с временем появления и пояснением, почему предмет
  подходит.

Интерфейс и документация — на русском. Версия приложения — **0.2.0**. Данные актуальны
на **26 октября 2026 года**, патч клиента **6967** (24 октября 2026).

---

## Важно: чего приложение не делает

- Не читает память Dota 2, не внедряется в процесс игры и не модифицирует её файлы.
- Не нажимает кнопки, не выбирает героев и не покупает предметы за вас.
- Не работает как «чит»: это оверлей-подсказка, решение принимаете вы.

Использование сторонних оверлеев — зона правил Valve и вашей ответственности.
Не используйте приложение в турнирах, где сторонний софт запрещён.

## Требования

- Windows 10/11.
- Python **3.12** (64-bit).
- Dota 2 в режиме **«Окно без рамки»** (Borderless Windowed). В полноэкранном
  эксклюзивном режиме снимок экрана может быть чёрным.
- Интернет при первом запуске: приложение скачивает героев, предметы, портреты и статистику.
- Желательно разрешение 1920×1080 и выше. При масштабе Windows 125–150 %
  калибровку всё равно нужно делать заново.

## Установка

1. Установите Python 3.12 с [python.org](https://www.python.org/downloads/windows/),
   включив **Add python.exe to PATH**.
2. Скопируйте папку проекта в удобное место (путь может содержать кириллицу).
3. Запустите `install.bat` — он создаст `.venv` и поставит зависимости.
4. Запустите `run.bat`.

Ручная установка:

```bat
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m app.main
```

Полезные ключи запуска:

```bat
run.bat --offline     :: только локальный кэш, без запросов в сеть
run.bat --no-gsi      :: не запускать локальный GSI-сервер
run.bat --port 32123  :: другой порт GSI
run.bat --debug       :: подробный лог в data/logs/app.log
```

`--offline` имеет смысл после хотя бы одного онлайн-запуска: без кэша данных не будет.

## Первый запуск: три шага

### 1. Установите GSI

Вкладка **«Настройки» → «Установить / обновить GSI»**.

Приложение создаёт файл:

```
<папка Dota 2>\game\dota\cfg\gamestate_integration\gamestate_integration_draftcopilot.cfg
```

GSI — официальный механизм Valve. Он нужен для трёх вещей:

- определить вашу сторону (`player.team_name`);
- определить вашего героя (`hero.id`) и игровое время;
- вовремя заметить переход к показу команд, чтобы заморозить драфт.

Сервер слушает только `127.0.0.1`, порт по умолчанию `32123`.
**Перезапустите Dota 2** после установки. Если GSI не нужен, сторону и героя можно
выбирать вручную — приложение продолжит работать.

### 2. Включите «Окно без рамки»

В Dota 2: **Настройки → Видео → Режим экрана → Окно без рамки**.
Оверлей должен находиться поверх игры.

### 3. Откалибруйте зоны портретов

Нажмите **«Калибровка»** (в шапке или на вкладке «Настройки»).

1. Зайдите в игру так, чтобы был виден экран выбора героев.
2. Обведите мышью **ровно пять портретов Radiant** — только портреты, без имён,
   рамок и панелей.
3. Обведите **пять портретов Dire**.
4. Нажмите **«Сохранить»**.

Кнопка **«Поменять местами»** меняет Radiant и Dire, если вы обвели не в том порядке.
Клавиша `R` сбрасывает рамки, `Esc` отменяет калибровку.

После сохранения приложение сделает тестовый снимок. Чтобы посмотреть, что именно
оно видит, нажмите **«Тестовый скан»** — откроется файл `data/debug/last_scan.png`
с рамками зон и распознанными героями.

> Если вы поменяли разрешение, масштаб Windows, монитор или режим экрана — откалибруйте заново.

## Как пользоваться

### Сторона

- **Авто (GSI)** — сторона берётся из `player.team_name`.
- **Radiant / Dire** — ручной выбор, если GSI не установлен или вы хотите проверить драфт
  за другую команду.

Сторона определяет, какой из двух обведённых рядов считается союзным, а какой — вражеским.
Приложение распознаёт **все 10 пиков с экрана**: блок `draft` в GSI доступен в основном
наблюдателям, поэтому экран остаётся основным источником.

### Ваш герой и роль

- «Мой герой» подставляется из GSI. Можно выбрать вручную; кнопка **«Из GSI»** возвращает
  автоматический режим.
- **Роль** (керри, мид, оффлейн, саппорт, хард-саппорт) фильтрует список контрпиков.
  «Любая» показывает более широкий, но менее точный список.

### Ручная правка драфта

- **Левый клик** по карточке — выбрать героя из списка.
- **Правый клик** — очистить слот или снять ручную блокировку.
- Ручной выбор блокируется: автоматический скан больше не перезапишет этот слот.
- Пустые слоты можно заполнять по мере появления пиков.

### Сканирование

- **«Скан»** — сделать снимок и распознать драфт сейчас.
- Автоскан по умолчанию включён, интервал 1,2 с. Он работает только во время драфта,
  если GSI сообщает игровое состояние, и не сканирует, пока открыта калибровка.
- На время скана окно может становиться прозрачным, чтобы не закрывать портреты.
- Результат стабилизируется по трём кадрам: одиночный сбой распознавания не меняет драфт.

### Заморозка драфта

- Как только распознаны все **10 разных героев**, драфт **замораживается**: приложение
  перестаёт сканировать экран. Переход на экран показа команд, загрузка карты и сам
  матч больше не могут затереть уже найденные пики.
- Дополнительно драфт замораживается, когда GSI сообщает состояние после пиков
  (`TEAM_SHOWCASE`, `WAIT_FOR_MAP_TO_LOAD`, `PRE_GAME`, `GAME_IN_PROGRESS`, `POST_GAME`).
  Это защищает даже частичный результат 9/10: недостающего героя можно добавить вручную.
- Пока драфт заморожен, кнопка **«Скан»** недоступна, а таймер автоскана остановлен.
  В шапке и нижней строке видна надпись «Драфт заморожен».
- **«Новый драфт»** очищает пики и снова включает сканирование. Автоматически это
  происходит при новом переходе клиента в выбор героев.

### Фильтры контрпиков

Под таблицей контрпиков есть строка фильтров:

- **поиск по имени** героя;
- **атрибут** (сила, ловкость, интеллект, универсальный);
- **тип атаки** (ближний/дальний бой);
- **сложность** 1–3 из файлов установленной игры;
- **сортировка**: по рекомендации, по имени A–Z, по сложности в обе стороны.

Без фильтров показывается топ-25. Фильтры и сортировка работают **внутри этих 25
предложенных героев** и не подмешивают остальных персонажей. Если поиск не нашёл
героя, значит, он не попал в топ-25 рекомендаций. Кнопка **«Сбросить»** возвращает
порядок рекомендаций.

### Вкладки

| Вкладка | Что показывает |
|---|---|
| **Контрпики** | Топ героев против врагов, преимущество, надёжность, причины; поиск и фильтры по атрибуту, атаке и сложности |
| **Предметы** | Старт / ранняя игра / мид / лейт / ситуативные предметы; крупные иконки, название и цена по наведению |
| **Нейтралки** | T1–T5, три лучших предмета на тир, время появления и доступность; название и причина по наведению |
| **Данные** | Патч, количество героев/предметов, состояние кэша, GSI, статус драфта, предупреждения |
| **Настройки** | GSI, калибровка, автоскан, монитор, прозрачность, время нейтральных предметов |

## Как считаются рекомендации

### Контрпики

Источник парных матчапов — публичное API **OpenDota**. Для каждого врага берётся
винрейт кандидата против него, затем:

1. применяется байесовское сглаживание с приором 60 игр;
2. считается нижняя граница Уилсона — она штрафует кандидатов с малой выборкой;
3. смешиваются преимущество по матчапам, нижняя граница и публичный винрейт героя;
4. добавляется синергия: закрывает ли герой нехватку инициации, контроля, фронтлайна,
   спасения, поддержки, урона и волнового клира;
5. применяется фильтр по роли, чтобы не предлагать саппорта на керри.

В колонке **«Надёжность»**:

- **высокая** — суммарно ≥ 700 матчей и ≥ 50 на пару;
- **средняя** — ≥ 250 и ≥ 20;
- **низкая** — меньше.

Публичные выборки OpenDota по парам героев часто небольшие (десятки матчей на пару),
поэтому «низкая» — это нормально, а не ошибка. Смотрите на преимущество и причины,
а не только на первое место.

### Предметы

- Берутся популярные предметы героя из OpenDota по фазам.
- Промежуточные компоненты (Broadsword, Yasha и т. п.) скрываются из мида и лейта,
  чтобы не выдавать их за готовые предметы.
- Готовые предметы, которые одновременно служат компонентом для более дорогой сборки
  (Aghanim's Scepter, Force Staff, Orchid, Diffusal Blade, Skull Basher, Maelstrom,
  Shadow Blade, Eul's Scepter и т. п.), остаются в списке — их покупают и используют
  как самостоятельный предмет.
- В раннюю игру не попадают предметы дороже 2500 золота, даже если OpenDota отнесла
  единичную покупку к ранней фазе.
- Ситуативные предметы строятся по тегам угроз врага: магия, физический урон, лечение,
  невидимость, иллюзии, уклонение, контроль, мобильность, спасение.
- Ситуативный список фильтруется по роли: керри и миду не предлагаются явно
  саппортные предметы (Pipe, Glimmer Cape, Guardian Greaves и т. п.), а саппортам —
  дорогие керри-предметы (Skadi, Butterfly, Satanic и т. п.).
- Если статистики нет, показывается базовый набор для роли.

Это эвристика, а не «идеальный билд». Порядок покупки и необходимость предмета
зависят от игры.

### Нейтральные предметы

Список тиров и время появления берутся **из файлов установленной игры**
(`scripts/npc/neutral_items.txt`), а не из сторонней таблицы. На патче 6967:

| Тир | Появление | Предметов |
|---|---|---|
| T1 | 0:00 | 12 |
| T2 | 15:00 | 9 |
| T3 | 25:00 | 9 |
| T4 | 35:00 | 9 |
| T5 | 60:00 | 10 |

Всего 49 предметов. Улучшения (enhancements) в пул не входят.
Предметы, удалённые Valve, автоматически перестают считаться нейтральными —
их нельзя получить в игре, поэтому и рекомендовать их нельзя.

Скоринг учитывает роль героя, его атрибут, теги предмета и угрозы вражеского драфта.
Показываются три лучших варианта на тир; предметы представлены крупными иконками,
а в тултипе — название, тир, причина и время появления. Время можно поправить
на вкладке «Настройки», если патч изменил правила.

## Данные и кэш

| Что | Откуда |
|---|---|
| Герои, роли, способности | OpenDota API |
| Публичный винрейт и пикрейт | OpenDota `heroStats` |
| Парные матчапы | OpenDota `/heroes/{id}/matchups` |
| Популярность предметов | OpenDota `/heroes/{id}/itemPopularity` |
| Названия, цены, компоненты предметов | `dotaconstants` |
| Тиры и время нейтральных предметов | файлы игры через VPK |
| Сложность героев (1–3) | файлы игры через VPK |
| Портреты и иконки | Steam CDN |
| Патч клиента | `steam.inf` установленной Dota 2 |

Кэш лежит в `data/cache/` и по умолчанию живёт 12 часов (настраивается
`data_ttl_hours` в `config.json`). Если сеть недоступна, приложение использует
устаревший кэш и пишет предупреждение. Нейтральные предметы и сложность героев
доступны всегда: они лежат в `data/neutral_items.json` и `data/hero_complexity.json`.

Кнопка **«Обновить данные»** на вкладке «Данные» перечитывает кэш/сеть.

## Настройки

Файл `config.json` создаётся рядом с `run.bat`.

| Поле | Смысл |
|---|---|
| `gsi_port` | порт локального GSI-сервера |
| `monitor` | номер монитора для `mss` (1 — первый физический) |
| `scan_interval` | интервал автоскана в секундах |
| `always_on_top` | держать окно поверх игры |
| `opacity` | прозрачность окна (0.6–1.0) |
| `boxes` | нормализованные зоны Radiant/Dire |
| `side_override` | `""`, `radiant`, `dire` |
| `role` | `""`, `carry`, `mid`, `offlane`, `support`, `hard_support` |
| `neutral_times` | время появления тиров в секундах |
| `auto_scan` | автоматическое сканирование |
| `scan_only_in_draft` | сканировать только когда GSI сообщает драфт |
| `transparent_on_scan` | делать окно прозрачным на время скана |
| `window_x/y/w/h` | положение и размер окна |

Настройки из интерфейса сохраняются кнопкой **«Сохранить настройки»**.
Положение и размер окна сохраняются при закрытии.

## Как безопасно проверить приложение

Не начинайте проверку с рейтингового матча. Лучший вариант — **пользовательское лобби
с ботами** (создайте Custom Lobby и заполните пустые слоты ботами). **Co-op vs Bots**
тоже подходит, если хочется сыграть с живыми союзниками.

- результат не влияет на MMR;
- в пользовательском лобби можно поставить паузу, осмотреться и спокойно проверить вкладки;
- доступны все 10 пиков и обычный экран выбора героев, как в настоящем матче;
- в лобби с ботами никто не пострадает, если приложение ошибётся или вы отвлечётесь,
  а рейтинг поведения не затрагивается.

**Single Draft** тоже не влияет на MMR, но для проверки он менее удобен: героев мало,
драфт идёт быстрее, а ошибки сложнее воспроизвести. Используйте его только как
дополнительный тест после ботов.

Короткий чек-лист:

1. Запустите лобби с ботами и дойдите до выбора героев.
2. Нажмите **«Тестовый скан»** и проверьте `data/debug/last_scan.png`: рамки должны
   точно охватывать пять портретов каждой команды.
3. Дайте автоскану заполнить драфт. Когда будут найдены все 10 героев, появится
   «Драфт заморожен», а «Скан» станет недоступен.
4. Проверьте контрпики (включая фильтры), предметы и нейтралок на своём герое.
5. Дождитесь экрана показа команд и начала матча — пики должны остаться на месте.
6. Перед следующим драфтом нажмите **«Новый драфт»** или просто перейдите в новый
   выбор героев: приложение разморозится автоматически.

Если что-то не распозналось, сохраните `last_scan.png` и `data/logs/app.log`.
Это позволит понять, дело в калибровке, разрешении или в изменившемся интерфейсе игры.

## Ограничения и точность

- **Нет эталонного скриншота 2026 года** в открытом доступе для проверки. Точность
  распознавания зависит от вашего разрешения, масштаба и калибровки. Обязательно
  проверьте «Тестовый скан».
- Геометрия карточек рассчитана по широким 16:9 карточкам клиента. Файлы данных
  проверены на клиенте 6967; если Valve изменит экран выбора героев, потребуется
  перекалибровка и, возможно, обновление шаблонов.
- Портреты на экране могут отличаться от картинок Steam CDN по кадрированию.
  Если распознавание путает героев, попробуйте обвести зоны плотнее по портретам
  и проверить `last_scan.png`. Небольшой сдвиг рамки (примерно до 5% ширины
  карточки) компенсируется автоматически, при большем — перекалибруйте.
- Приложение не полагается на GSI `draft`: в обычном матче он может быть пустым
  или неполным, поэтому пики распознаются с экрана. После 10/10 драфт замораживается.
- OpenDota не даёт больших выборок по парам героев; рекомендации сглажены, но остаются
  вероятностными.
- Сборка предметов — популярность + эвристики по угрозам, а не симуляция конкретной игры.
- Приложение не учитывает баны, порядок пиков, сторону карты и синергию конкретных игроков.
- В полноэкранном эксклюзивном режиме снимок может быть чёрным. Используйте «Окно без рамки».
- При смене монитора/разрешения калибровка сбрасывается не автоматически — проверяйте её.

## Если что-то не работает

**Портреты не распознаются**

1. Проверьте, что Dota в режиме «Окно без рамки».
2. Сделайте «Тестовый скан» и посмотрите `data/debug/last_scan.png`: рамки должны
   точно охватывать пять портретов.
3. Убедитесь, что выбран правильный монитор в настройках.
4. Перекалибруйте при том же разрешении и масштабе Windows.

**GSI не подключается**

1. Проверьте, что файл лежит в `game/dota/cfg/gamestate_integration/`.
2. Перезапустите Dota 2.
3. Проверьте, что порт `32123` не занят другим приложением (`--port` поможет).
4. В логе `data/logs/app.log` будет причина.

**Нет данных / пустые списки**

1. Первый запуск требует интернет.
2. Нажмите «Обновить данные».
3. Проверьте вкладку «Данные»: есть ли предупреждения и возраст кэша.
4. `--offline` работает только при наличии кэша.

**Окно закрывает портреты**

Включите «Делать окно прозрачным на время скана» или перетащите окно на другой монитор.

**Слишком широкий список контрпиков**

Выберите роль и воспользуйтесь фильтрами по атрибуту, типу атаки или сложности.
Фильтры сужают только топ-25 предложенных героев. Фильтр по роли намеренно строгий:
герой с тегом Support не попадёт в керри. Кнопка «Сбросить» возвращает порядок
рекомендаций.

## Разработка

Структура:

```
app/
  main.py        точка входа, логирование
  config.py      настройки, нормализованные зоны
  gsi.py         локальный HTTP-сервер GSI и парсер
  steam.py       поиск Dota 2, установка GSI, steam.inf
  capture.py     захват экрана через mss
  vision.py      шаблоны портретов, распознавание, debug-кадр
  data.py        OpenDota, кэш, профили героев и предметов
  gamedata.py    нейтральные предметы и сложность героев из файлов игры
  recommend.py   контрпики, предметы, нейтралки
  controller.py  фоновая загрузка, автоскан, стабилизация драфта
  ui.py          окно, калибровка, вкладки
  theme.py       тёмная тема
  assets.py      иконки предметов
data/
  neutral_items.json   тиры/время из neutral_items.txt
  hero_complexity.json сложность 1–3 из файлов героев
  cache/               кэш API и картинок
  debug/               тестовые кадры
tools/
  import_game_data.py  извлечение нейтралок и сложности из VPK
  smoke_data.py        проверка живых данных и рекомендаций
  ui_smoke.py          офскрин-проверка интерфейса
tests/                 pytest
```

Тесты:

```bat
.venv\Scripts\python.exe -m pytest -q
```

Проверка живых данных:

```bat
.venv\Scripts\python.exe tools\smoke_data.py
```

Офскрин-проверка UI (без окна):

```bat
.venv\Scripts\python.exe tools\ui_smoke.py
```

Проверка с настоящим рендерингом (нужна для кириллицы и шрифтов):

```bat
set DDC_SMOKE_NATIVE=1
.venv\Scripts\python.exe tools\ui_smoke.py
```

Обновление нейтральных предметов и сложности героев после патча (нужны установленный
`vpk` и Dota 2):

```bat
.venv\Scripts\python.exe tools\import_game_data.py
```

Скрипт читает `scripts/npc/neutral_items.txt` и `Complexity` из
`scripts/npc/heroes/npc_dota_hero_*.txt` в `pak01_dir.vpk`, затем перезаписывает
`data/neutral_items.json` и `data/hero_complexity.json`. После этого проверьте
`client_version` в обоих файлах и тиры/время в приложении.

## Приватность

- GSI-сервер слушает только `127.0.0.1`.
- Наружу уходят только запросы к OpenDota, GitHub (`dotaconstants`) и Steam CDN.
- Скриншоты не отправляются никуда; отладочный кадр сохраняется локально в `data/debug/`.
- Конфиг и кэш лежат в папке проекта.
